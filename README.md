# Expense Tracker

A simple full-stack expense tracking application built with Java, Spring Boot, MySQL, HTML, CSS, and JavaScript.

The application allows users to add, view, delete, and filter expenses while calculating total spending dynamically.

## Features

- Add new expenses
- View all expenses
- Delete expenses
- Calculate total spending
- Filter expenses by category
- Store expense data in MySQL
- REST API based backend
- Simple responsive frontend
